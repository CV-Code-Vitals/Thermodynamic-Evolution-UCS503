# Self-Healing Pipeline Benchmark Repository

This repository is a self-contained, multi-category benchmark suite designed to evaluate autonomous repository intelligence, diagnostic verification, remediation planning, and isolated execution engines.

It contains 15 ground-truth injected defects and 6 benign clean control fixtures across 8 software engineering dimensions:
1. Structural Complexity
2. Reliability & Error Handling
3. Security & Injection Vulnerabilities
4. Dependencies & Container Packaging
5. Architectural Layer Boundaries & Circularities
6. Test Coverage & Critical Logic
7. Maintainability & Code Duplication
8. Documentation of Exported APIs
