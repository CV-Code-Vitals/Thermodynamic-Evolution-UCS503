## 1. Executive Summary

Milestone 3.0 introduced `benchmarks/self_healing_suite_v2`, expanding the benchmark surface from 21 fixtures to 96 fixtures across 8 categories. 

This audit evaluates whether Suite v2 represents genuine out-of-distribution generalization or programmatic template replication. Using AST statement hashing, normalized lexical comparisons, and partition integrity analysis (persisted in [milestone3_1_duplicate_analysis.json](file:///E:/SWE/reports/milestone3_1_duplicate_analysis.json) and [milestone3_1_partition_integrity.json](file:///E:/SWE/reports/milestone3_1_partition_integrity.json)), this audit establishes:

1. **Zero Exact Byte-Level Duplicates:** No two files in Suite v2 share identical raw file content.
2. **High Structural Template Overlap (62.5%):** Suite v2 was constructed using parameterized programmatic generators (`v2_builder.go`). Fixtures within each category (e.g. `nesting_1.go` through `nesting_4.go`, `duplicate_fn_1.go` through `duplicate_fn_8.go`) share identical AST statement structures with altered variable names and numeric constants.
3. **Partition Integrity Limitation:** Suite v2 is an expanded synthetic multi-category benchmark suite, not an open-domain held-out production codebase. High diagnostic accuracy on Suite v2 measures systematic rule coverage rather than zero-shot open-domain reasoning.
